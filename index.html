05 — Edge Detection

Window Scanning — Smoothing, Edge, LoG/DoG
Average/Gaussian, Prewitt/Sobel ครบ 8 ทิศ, Roberts, LoG, DoG — เติม noise แล้ว hover ดูค่าพิกเซลและการคำนวณ kernel จริง
Filtering
Laplacian of Gaussian — จากไหนมา ทำไมต้องมี
ไล่เหตุผลทีละขั้น: ทำไม blur ก่อน HPF, รวม Gaussian+Laplacian เป็น operator เดียว, ไปจนถึงสูตรปิด — ดูได้ทั้ง 1D และ 2D
LoG
Live DoG Filter — วิดีโอสด/ไฟล์ ผ่าน Difference of Gaussians
เปิดกล้องหรืออัปโหลดไฟล์วิดีโอ กรองแบบ real-time ด้วย DoG ทั้งหมดในเบราว์เซอร์ ปรับ σ, k, gain แล้วดูขอบเปลี่ยนสด ๆ
DoG / Real-time

08 — Fourier Transforms

Nyquist & Aliasing — ทำไมสุ่มไม่พอถึง "จำผิดความถี่"
