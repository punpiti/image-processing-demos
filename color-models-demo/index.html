01204483 Image Processing — Topic 04, Color Processing

สี 6 โมเดล — RGB, HSV, HSL, XYZ, YCrCb, CMYK

เลือกรูป แล้วเอาเมาส์ชี้จุดสีบนรูป — ตำแหน่งของสีเดียวกันนั้นจะปรากฏพร้อม กันในไดอะแกรมทั้ง 6 โมเดล นอกจากดูอย่างเดียว ยังลากค่าในโมเดลไหนก็ได้เพื่อ "ตั้งสี" เอง แล้วดูตำแหน่งเดียวกันขยับพร้อมกันในทุกโมเดลที่เหลือ

สีหนึ่งจุดคือพิกัดเดียวกันที่ถูก "แปลภาษา" เป็นหลายระบบพร้อมกัน — เปลี่ยนระบบไม่ได้เปลี่ยนสี เปลี่ยนแค่วิธีอธิบายตำแหน่งของมัน

RGB คือลูกบาศก์เติมแสง (additive) — CMYK คือด้านตรงข้าม (subtractive) ใช้กับหมึกพิมพ์ ไม่ใช่แสง

HSV/HSL แยก "เนื้อสี" (Hue มุมบนวงล้อ) ออกจาก "ความอิ่มตัว/ความสว่าง" — ใกล้เคียงวิธีที่คนอธิบายสีในชีวิตจริงมากกว่า RGB

YCrCb แยกความสว่าง (Y) ออกจากสี (Cr,Cb) — เป็นเหตุผลที่ทำให้บีบอัดวิดีโอ/JPEG ทิ้งรายละเอียดสีได้มากกว่าความสว่างโดยตาแทบไม่รู้สึก

XYZ คือระบบอ้างอิงที่สร้างจากการมองเห็นของมนุษย์ล้วน ๆ ไม่ผูกกับอุปกรณ์ใด — แผนภาพ CIE xy ด้านล่างคือค่าประมาณเพื่อการสอน ไม่ใช่ตำแหน่งที่แม่นยำระดับมาตรฐาน

1 · เลือกรูปภาพ

RGB(0,0,0)

เอาเมาส์ชี้บนรูป หรือลากค่าในโมเดลด้านล่างเพื่อกำหนดสีเอง

2 · โมเดลสี — hover บนรูป หรือลากตัวเลขด้านล่างของโมเดลไหนก็ได้

RGB → HSV/HSL: หา max,min,delta ของ (r,g,b) แล้วคำนวณ Hue จากว่าช่องใด max, Value=max, Lightness=(max+min)/2
RGB → CMYK: K=1−max(r,g,b); C=(1−r−K)/(1−K); M=(1−g−K)/(1−K); Y=(1−b−K)/(1−K)
RGB → XYZ (sRGB, D65): gamma-expand แต่ละช่อง แล้วคูณเมทริกซ์ 3×3 มาตรฐาน sRGB→XYZ; chromaticity x=X/(X+Y+Z), y=Y/(X+Y+Z)
RGB → YCrCb: Y=0.299R+0.587G+0.114B; Cr=128+0.713(R−Y); Cb=128+0.564(B−Y)
ตัวเลขและไดอะแกรมสร้างจากสูตรแปลงสีมาตรฐาน (sRGB/D65 สำหรับ XYZ, BT.601-style สำหรับ YCrCb) เพื่อการสอน — แผนภาพ CIE xy chromaticity เป็นค่าประมาณของ spectral locus จริง
